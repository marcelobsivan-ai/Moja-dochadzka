# Moja dochádzka – PWA

## Nasadenie na GitHub Pages
1. Vytvor nový verejný GitHub repozitár, napr. `moja-dochadzka`.
2. Nahraj všetky súbory z tohto priečinka do koreňa repozitára.
3. V repozitári otvor **Settings → Pages**.
4. V časti **Build and deployment** vyber **Deploy from a branch**, branch `main`, folder `/ (root)` a ulož.
5. Po publikovaní GitHub zobrazí verejnú adresu stránky.

## Pridanie na Android
1. Otvor verejnú HTTPS adresu v Chrome.
2. Otvor menu ⋮ a vyber **Pridať na plochu** alebo **Inštalovať aplikáciu**.
3. Potvrď pridanie. Na ploche sa zobrazí ikona Dochádzka.

## Dôležité
- Údaje sa ukladajú iba v lokálnom prehliadači daného zariadenia.
- Zdieľaná databáza, synchronizácia a používateľské účty nie sú súčasťou tejto verzie.
- Pri vymazaní dát prehliadača sa môžu vymazať aj záznamy. Pravidelne exportuj CSV/PDF.
- Výpočet zárobku je orientačný; nezohľadňuje príplatky, dane, odvody ani zrážky.
